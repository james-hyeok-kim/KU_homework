# Code Description & Reproduction Guide
# GLOW vs FLUX: Comparing Normalizing Flows and Flow Matching at 64x64
# =====================================================================

## Project Overview

This project empirically compares three families of generative models for
64x64 face image synthesis:
  - GLOW (Normalizing Flow, 76M params, trained from scratch on FFHQ-64)
  - FLUX.1 (Flow Matching DiT, ~12B params, pretrained)
  - DDPM/DDIM (Denoising Diffusion, 113M params, pretrained on CelebA-HQ-256)

Evaluation covers FID, exact NLL (GLOW only), reconstruction PSNR/SSIM,
latent interpolation, OOD detection, and sampling efficiency (NFE/wall-clock).


## Directory Structure

This repository contains code only. Data is provided separately
as final_project_data.tar.gz (see "Data Setup" section below).

  make_figures.py   Regenerate all paper figures (fig1-9) in one command

## Reproduction Steps

### 0. Install dependencies
    pip install -r requirements.txt

    # PyTorch with CUDA (match your CUDA version):
    pip install torch==2.9.1+cu130 torchvision==0.24.1+cu130 \
        --index-url https://download.pytorch.org/whl/cu130

### 1. Set up data (from final_project_data.tar.gz)
    # Extract the provided data archive to /data/jameskimh/:
    tar -xzf final_project_data.tar.gz -C /data/jameskimh/

    # This will create:
    #   /data/jameskimh/final_project/data/ffhq64/     (FFHQ images)
    #   /data/jameskimh/final_project/glow_pretrained/ (GLOW checkpoints)
    #   /data/jameskimh/final_project/samples/         (pre-generated samples)
    #   /data/jameskimh/final_project/logs/            (FID results)

    # To skip re-training and use the provided checkpoint directly,
    # jump to step 3 (evaluate) or step 5 (FLUX sampling).

### 2. Train GLOW from scratch
    cd code/
    python train.py

    # Key hyperparameters (see train.py):
    #   lr=5e-5, warmup=1000 steps, batch=128, steps=30000
    #   4 blocks x 32 flows, hidden_channels=512
    #   Checkpoint saved every 5000 steps to:
    #     /data/jameskimh/final_project/glow_pretrained/

    # To monitor training with auto-restart on crash:
    bash run_train_with_watchdog.sh

### 3. Evaluate GLOW (NLL + FID)
    python evaluate.py
    # Outputs: NLL (bits/dim) on val set, FID vs FFHQ-64 (5k samples)

### 4. GLOW reconstruction (PSNR / SSIM)
    python reconstruct.py
    # Evaluates 200 val images: encode -> decode -> compare

### 5. Generate FLUX.1 samples
    # FLUX.1-schnell (NFE=4, default):
    python sample_flux.py --model schnell

    # FLUX.1-dev (NFE=28, default):
    python sample_flux.py --model dev

    # FLUX.1-dev with custom NFE (e.g., 8):
    python sample_flux.py --model dev --nfe 8

    # Pretrained weights expected at:
    #   /data/jameskimh/flux_pretrained/FLUX.1-schnell/
    #   /data/jameskimh/flux_pretrained/FLUX.1-dev/

### 6. Generate DDIM / DDPM samples + FID
    python sample_ddim.py
    # Generates 5000 samples each for ddim_10/20/50 and ddpm_100
    # Uses google/ddpm-celebahq-256 (auto-downloaded from HuggingFace)
    # Computes FID for each variant; results saved to logs/ddim_results.json

    # Generate specific variants only:
    python sample_ddim.py --variants ddim_50 ddpm_100

### 7. GLOW latent space interpolation
    python interpolation.py
    # Saves fig6_interpolation.png to experiments/results/

### 8. OOD detection via NLL
    python ood_detection.py
    # Tests NLL on FFHQ faces, solid colors, and random noise
    # Saves fig7_ood_detection.png and logs/ood_results.json

### 9. 2D transport path visualization
    python visualize_2d.py
    # Trains lightweight 2D models (NF, FM, DDPM) on two-moons dataset
    # Saves fig8_transport_paths.png and fig9_twomoons_4way.png

### 10. Regenerate all paper figures at once
    python make_figures.py              # regenerate all fig1-9
    python make_figures.py --figs 2 3  # regenerate specific figures only


## How the Code Works

### GLOW (model.py + train.py)

The model implements the multi-scale GLOW architecture:
  - Each GlowBlock contains n_flows sequential flow steps
  - Each step applies: ActNorm -> InvConv -> AffineCoupling
  - Non-final blocks split off half the channels as latents (z_split)
    and squeeze the remaining activations before the next block
  - Training maximizes log p(x) = log p_Z(f(x)) + sum(log|det(df/dx)|)

Two key stability modifications vs. standard GLOW:
  1. AffineCoupling log-scale clamped to [-3, 3]
     (default [-5,5] allows e^5~148x amplification per step -> divergence)
  2. Gradient validity check: optimizer step is skipped if any gradient
     contains NaN or Inf (training would otherwise diverge at step ~300-500)

Sampling: model.sample(n, temperature) draws z ~ N(0, T^2*I) for each
latent and applies the reverse pass through all blocks.

### DDIM / DDPM (sample_ddim.py)

Uses HuggingFace diffusers with google/ddpm-celebahq-256:
  - DDPMPipeline for stochastic sampling (DDPM-100)
  - DDIMScheduler for deterministic ODE sampling (DDIM-10/20/50)
  - All outputs generated at 256x256, then bicubically downsampled to 64x64

### FID Evaluation

All FID scores use clean-fid (cleanfid library) with:
  - 5,000 generated samples
  - 70,000 FFHQ-64 real images as reference
  - Default InceptionV3 features
