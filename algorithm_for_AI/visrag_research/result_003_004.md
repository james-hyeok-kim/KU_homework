## 분석

### 1. InfoVQA: 세 방법 모두 동일 (+1.19%p vs baseline)

- 분류기가 InfoVQA 전 페이지를 **100% mixed**로 판정 (인포그래픽 특성)
- selective / chart_aware 모두 Hybrid와 동일한 OCR 경로 → 완전히 동일한 결과
- chart_aware는 route+OCR 캐시 재활용으로 avg_ocr=0.055s (사실상 무료 재실행)

### 2. ChartQA: 모든 OCR 개입이 baseline 이하 ✗

라우팅 레이블 (63 페이지):

| 레이블 | 수 | 비율 |
|--------|-----|------|
| chart | 52 | 83% |
| mixed | 11 | 17% |
| text | 0 | 0% |

| 방법 | ANLS | EM | Δ vs baseline |
|------|------|-----|--------------|
| baseline | 0.6941 | 0.6667 | — |
| DocParse Hybrid | 0.6757 | 0.6190 | -1.84%p |
| chart_aware_routing | 0.6693 | 0.6032 | -2.48%p |
| selective_routing | 0.6624 | 0.6349 | -3.17%p |

- chart(83%): selective는 skip, chart_aware는 차트 특화 OCR 적용
- mixed(17%): 두 방법 모두 일반 OCR → 이 11개 샘플 ANLS≈0.51 (역계산)
- chart_aware가 selective보다 +0.69%p 개선 (차트 특화 OCR이 일부 효과)
- 그러나 baseline 대비 여전히 -2.48%p
- **결론**: ChartQA는 OCR 개입 자체가 해로움. 순수 시각적 접근(baseline)이 최선

### 3. DocVQA: Selective 큰 개선, Chart-Aware도 개선 ★★

- selective_routing: **+1.04%p** vs baseline (hybrid는 -0.44%p → +1.48%p 역전)
- chart_aware_routing: +0.38%p vs baseline (hybrid보다 +0.82%p)
- selective > chart_aware: DocVQA에 chart 페이지가 소수 있고, 차트 특화 OCR이 plain-text 문서에 노이즈 추가
- text(~50%) → OCR 스킵: VLM이 직접 정확히 읽음
- mixed(~50%) → OCR 적용: 표·양식 구조 정보 보완
- **선택적 OCR이 일괄 OCR보다 효과적**임을 확인

### 4. SlideVQA: Hybrid ≈ Selective > Chart-Aware

| 방법 | ANLS | Δ vs baseline |
|------|------|--------------|
| baseline | 0.7458 | — |
| DocParse Hybrid | 0.7472 | +0.14%p |
| selective_routing | 0.7469 | +0.11%p |
| chart_aware_routing | 0.7412 | -0.46%p |

- chart_aware의 chart 특화 OCR이 슬라이드 차트 페이지에서 오히려 혼란 유발
- selective(skip chart)가 chart_aware(chart OCR)보다 나음 → 슬라이드 차트도 직접 읽는 게 유리

## 결론

1. **Selective Routing이 DocVQA에서 +1.04%p** — 선택적 OCR이 일괄 OCR의 한계를 극복
2. **Chart-Aware OCR (C) vs Selective (D)**: ChartQA +0.69%p 개선, 나머지 데이터셋에서 selective보다 열위
3. **InfoVQA**: 분류기가 전부 mixed → 세 방법 동일 결과
4. **ChartQA**: OCR 개입 자체가 해로움 — baseline이 최선, 차트 특화 OCR도 역부족
5. **핵심 인사이트**: 문서 유형별 OCR 라우팅이 효과적이지만, 분류기 오류(mixed 오판)가 성능 저하의 주 원인

### 제안하는 후속 실험

- **더 정밀한 분류기**: ChartQA의 17% "mixed" 오판을 줄일 수 있는 dedicated classifier
- **ChartQA 전략**: OCR 없이 차트 수치 추론 특화 프롬프트로 직접 접근
- **데이터셋 맞춤 전략**: InfoVQA hybrid + DocVQA selective + ChartQA baseline 자동 선택 라우터
